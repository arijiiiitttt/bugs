# Top K frequent elements

**Track:** Algorithms & data structures &nbsp;|&nbsp; **Difficulty:** Medium &nbsp;|&nbsp; **Stack:** Node.js (ES modules, no extra dependencies)

## Task

## Overview
Implement `topKFrequent(nums, k)` in `src/topK.js`. Return the `k` most frequent values.

### Rules
- Order the result by frequency descending; ties are broken by the **smaller value first**.
- If `k` exceeds the number of distinct values return all of them. `k <= 0` returns `[]`.
- Inputs up to 100,000 numbers must finish quickly.
