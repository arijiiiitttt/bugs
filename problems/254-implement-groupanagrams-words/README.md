# Implement groupAnagrams(words)

**Track:** Algorithms & data structures &nbsp;|&nbsp; **Difficulty:** Easy &nbsp;|&nbsp; **Stack:** Node.js (ES modules, no extra dependencies)

## Task

## Overview
Implement `groupAnagrams(words)` in `src/groupAnagrams.js`. Group words that are anagrams of each other.

### Rules
- Return an array of groups (arrays of words).
- Groups appear in order of the first word that started them; inside a group words keep input order.
- Comparison is case-sensitive (`'Ab'` and `'ba'` are **not** anagrams).
- The empty string is a valid word. Duplicate words are kept.
