# Implement isValidBrackets(s)

**Track:** Algorithms & data structures &nbsp;|&nbsp; **Difficulty:** Easy &nbsp;|&nbsp; **Stack:** Node.js (ES modules, no extra dependencies)

## Task

## Overview
Implement `isValidBrackets(s)` in `src/brackets.js`. Return `true` if every `()`, `[]`, `{}` in the string is properly opened, closed and nested.

### Rules
- Any other characters are ignored: `isValidBrackets('a(b[c]{d})')` is `true`.
- `'(]'`, `'([)]'`, `'(('` and `')('` are invalid.
- The empty string is valid.
